# Security Policy

## Supported Versions

The `main` branch is the only supported version at this time. Tagged
releases follow.

| Version | Supported          |
|---------|--------------------|
| main    | :white_check_mark: |
| < 0.1.x | :x:                |

## Reporting a Vulnerability

**Do not file public GitHub issues for security vulnerabilities.** Instead,
email the repository owner directly. We will acknowledge within 72 hours and
keep you posted on the fix timeline.

When reporting, include:

* A description of the issue, severity, and impact.
* A minimal reproducer (test, script, or `curl` invocation).
* Affected crate(s) and commit hash.
